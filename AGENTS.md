# ACVC

Run `acvc assistant` before using ACVC or explaining it. The command returns the operational contract in this computer's language.

If this session has the ASB MCP, submit that command's `documents` array to `rag.index` once. Later context search uses `rag.search`.

Call the `acvc` executable, or `acvc mcp` when that server is already registered. Do not open `.acvc/graph.sqlite`, the log, or the pack. JSON status values stay `na fronteira`, `superada`, `rejeitada`, and `sem medição`.
