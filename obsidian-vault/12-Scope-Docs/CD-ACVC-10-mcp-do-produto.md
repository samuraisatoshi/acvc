## Problema
O agente chama o executável. Ainda não há ferramenta MCP do próprio ACVC.

## Valor
Os verbos do produto ficam disponíveis como ferramentas, com o mesmo JSON do CLI.

## Fronteiras
Não é o MCP do ASB. Não abre o armazenamento por FFI. Não cria um segundo modelo.
