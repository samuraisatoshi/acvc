# UI web

## Problema
A TUI e os plugins de editor não servem quem abre um navegador.

## Valor
Campanha, fronteira, linhagem, premissa, comparação e busca aparecem numa página, lendo o mesmo motor.

## Fronteiras
Não substitui a TUI. Não fala com o armazenamento por FFI. Não é o corte 0.1.
