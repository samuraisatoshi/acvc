# TUI

## Problema
Nenhuma IDE desenha o grafo de hipóteses, e um hash com uma cola de teclas não serve a uma pessoa.

## Valor
A pessoa vê a premissa primeiro, a fronteira com as métricas, e muda de tela sem decorar comando.

## Fronteiras
A TUI usa os mesmos casos de uso. Não raspa texto do CLI. Não é a UI web.
