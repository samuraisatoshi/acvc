# Как пользоваться

Шаги ниже используют имена команд. Гипотеза — это одна попытка. Измерение — это одна проба. Попытки, которые никто не обошёл по каждому числу, — это граница.

1. `acvc context --campaign IMYA` прежде чем предлагать, измерять или отбрасывать.
2. Если кампании нет: `acvc init --repo .` и `acvc campaign create IMYA --metric mera:higher`.
3. Первая гипотеза — `seed` папки с файлами гипотезы, с `--premise`, `--assumption`, `--intent` и `--agent`.
4. Файл изменился: `record` от родителя. Не делайте второй `seed`.
5. Есть настоящее число объявленной меры: `score`. Неполная проба не входит на границу.
6. `frontier` показывает, что ещё соревнуется. `why` объясняет одну гипотезу. `recall --query` находит её по тексту посылки.
7. Два конкретных измерения: `compare`.
8. Гипотеза умерла по известному мотиву: `reject --reason`. Без мотива не отклоняйте. Чтение уже говорит, что мотив не записан.
9. Сессия потратила токены, и это число известно: `spend`. Не оценивайте.
10. Вариант, который победил, входит в Git через `promote` в checkout, который уже есть.

Префикс идентификатора: от 8 до 64 шестнадцатеричных знаков, без двусмысленности.

Для другого агента на той же машине канал — программа или `acvc mcp`. Страница и TUI — для человека. Не заменяйте их прямым чтением базы.
