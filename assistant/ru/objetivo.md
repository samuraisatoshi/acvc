# Цель

Git должен получить попытку, которую человек одобрил. Агент кода пробует много версий одного изменения, откатывается, меняет мнение и забывает сессию. Если каждая неудачная попытка становится коммитом, репозиторий заполняется, и следующий агент теряется в этой истории.

ACVC записывает каждую попытку: идею, файлы и числа. Видно, какие попытки ещё соревнуются. `promote` копирует одобренные файлы в checkout Git, который уже есть. ACVC не делает merge и не заменяет историю Git.

Когда объясняете ACVC человеку, который его не видел, начните с этого. Имена ниже — те, которыми пользуются команды.

Объект — вариант: гипотеза с посылкой, деревом Меркла и пробами только на добавление. Кампания объявляет меры. Граница — множество того, что измерение ещё не превзошло. Recall находит посылку по тексту, со статусом и родителем.

Мотив — следующая сессия. Ей нужно найти то, что ещё соревнуется, не перечитывая чат, не принимая последний `score` за истину и не сливая две гипотезы, которые меряют несравнимое.

Git остаётся складом победившего варианта в checkout, который уже есть. ACVC не заменяет историю Git и не делает merge.
