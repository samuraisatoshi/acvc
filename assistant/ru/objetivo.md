# Цель

Git хранит то, что человек решил записать. Агент кода проверяет гипотезы пачками, откатывается, переписывает посылку и забывает сессию. Следующий коммит не говорит, какое измерение ещё соревнуется и почему другое бросили.

ACVC существует ради этой памяти.

Объект — вариант: гипотеза с посылкой, деревом Меркла и пробами только на добавление. Кампания объявляет меры. Граница — множество того, что измерение ещё не превзошло. Recall находит посылку по тексту, со статусом и родителем.

Мотив — следующая сессия. Ей нужно найти то, что ещё соревнуется, не перечитывая чат, не принимая последний `score` за истину и не сливая две гипотезы, которые меряют несравнимое.

Git остаётся складом победившего варианта в checkout, который уже есть. ACVC не заменяет историю Git и не делает merge.
