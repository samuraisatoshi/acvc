# Trade-offs

Используйте это, когда есть две или больше измеренных попыток и числа не сходятся. Один прямой путь, без второй попытки, не нуждается в кампании.

## Пользуйтесь ACVC, когда

- Сессия проверяет больше одной гипотезы, и следующей нужно знать, какая ещё соревнуется.
- Посылка меняется, и мотив отказа важен не меньше числа.
- Последняя проба сама по себе не лучшая.
- Несколько мер тянут в разные стороны, и обе гипотезы должны остаться видимыми.
- Другой агент часы спустя сделает recall вместо перечитывания чата.

## Не пользуйтесь, когда

- Работа — один линейный путь, и Git уже рассказывает нужную историю.
- Нет объявленной меры и нет посылки. Без этого ACVC становится вторым Git без границы.
- Вопрос только «что сейчас в working tree». Это `git status` или `acvc status`, не новая кампания.
- Цена записи посылки, причины и измерения выше цены забыть попытку.

## Что вы получаете

Память гипотезы, границу Парето, recall посылки, мотив отдельно от счёта и склад Git только победившего варианта.

## Чем платите

Хранилище `.acvc` рядом с Git. Дисциплину не открывать его руками. Меру, объявленную до пробы. У обхода свой список, поэтому большой файл входит в хеш, если его нет в `.acvcignore` и нет в фиксированном списке пропуска. Удалённая сторона копирует объекты. Она не делает merge, который сделал бы Git.

## Агенты в Cursor, Claude Code и OpenCode

Ресурс, который они должны вызывать, — `acvc` в `PATH` или сервер `acvc mcp`, если сессия его уже зарегистрировала. Оба говорят на JSON. Ни один не открывает SQLite. Эта папка говорит контракт. Код программы остаётся реализацией.
