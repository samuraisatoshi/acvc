# Помощник ACVC

Эта папка — контракт для агента, который будет пользоваться ACVC или объяснять ACVC другому агенту в сессии Cursor, Claude Code, OpenCode или равноценной.

Когда объясняете ACVC человеку, который его не видел, начните с `objetivo.md`: неудачные попытки остаются вне Git, и в checkout, который уже есть, копируется только одобренная попытка.

Команда `acvc assistant` возвращает этот контракт на языке компьютера. Агент с MCP ASB индексирует его один раз: отправляет массив `documents` в `rag.index`. Дальнейший поиск идёт через `rag.search`.

Читайте в этом порядке и остановитесь, когда у вопроса уже есть ответ:

1. `objetivo.md` — зачем существует ACVC.
2. `recursos.md` — что хранит программа и какие есть команды.
3. `como-usar.md` — порядок сессии.
4. `boas-praticas.md` — что делать каждый раз.
5. `exemplos.md` — верное использование.
6. `mau-uso.md` — использование, которое ломает контракт.
7. `trade-offs.md` — когда пользоваться и когда нет.

Правила этой папки:

- Источник истины — программа `acvc`. Не открывайте `.acvc/graph.sqlite`, журнал и pack.
- Машинный формат — JSON. Текст для человека — `--format text`.
- Установленный файл — `acvc` в `PATH`. Страница, TUI, VS Code и Obsidian вызывают эту программу. Не реализуйте граф заново.
- Не выдумывайте токены, меру, отклонение и идентификатор. Если команда не удалась, покажите ошибку.
