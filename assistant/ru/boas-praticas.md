# Практики

Запишите убеждение словами человека. Оставьте каждую попытку. Худшее число не удаляет попытку и не пишет причину за вас.

- Посылка — это проблема на языке человека. Хеш не имя гипотезы.
- Каждая причина остаётся у гипотезы, которая её допускает. Несколько причин не становятся одной фразой кампании.
- `context` — первое чтение сессии. `frontier` отвечает, что ещё соревнуется. `why` отвечает на одну гипотезу.
- Запишите полную пробу по каждой мере схемы. Граница игнорирует неполную пробу.
- Оставьте худшую пробу в истории. Она документирует попытку.
- Отклоняйте только с мотивом, который написал тот, кто решил. Доминирование — не смерть.
- Используйте `.acvcignore` в посеянной папке для того, что не является гипотезой. Не полагайтесь на `.gitignore` Git.
- Хранилище следует за `--repo`. Маркеры остаются в посеянной папке.
- Показывайте посылку, статус и меру. Хеш показывайте только тогда, когда агенту нужно передать идентификатор другой команде.
- `recall` одним словом из посылки, включая ударение. Пустой поиск или поиск из одной пунктуации — ошибка.
- `spend` записывает то, что сессия действительно потратила. Это не бюджет, не мера, и он не блокирует `record`.
- Страница, TUI, VS Code и Obsidian уже говорят посылкой. Не открывайте SQLite снова, чтобы «улучшить» просмотр.
