# Praktyki

Zapisz przekonanie słowami osoby. Zostaw każdą wersję. Gorsza liczba nie kasuje wersji i nie zapisuje powodu za ciebie.

- Przesłanka jest problemem w języku człowieka. Hash nie jest nazwą hipotezy.
- Każda przyczyna zostaje przy hipotezie, która ją zakłada. Kilka przyczyn nie staje się jednym zdaniem kampanii.
- `context` jest pierwszym odczytem sesji. `frontier` odpowiada, co wciąż konkuruje. `why` odpowiada na jedną hipotezę.
- Zapisz pełną próbę dla każdej miary schematu. Granica pomija próbę niepełną.
- Zostaw gorszą próbę w historii. Dokumentuje ona próbę.
- Odrzucaj tylko z motywem napisanym przez tego, kto zdecydował. Dominacja nie jest śmiercią.
- Użyj `.acvcignore` w zasianym folderze dla tego, co nie jest hipotezą. Nie licz na `.gitignore` Gita.
- Magazyn idzie za `--repo`. Znaczniki zostają w zasianym folderze.
- Pokaż przesłankę, status i miarę. Hash pokazuj tylko wtedy, gdy agent musi podać identyfikator innemu poleceniu.
- `recall` jednym słowem z przesłanki, także z akcentem. Puste szukanie albo samo ze znaków przestankowych jest błędem.
- `spend` zapisuje to, co sesja naprawdę zużyła. To nie budżet, nie miara i nie blokuje `record`.
- Strona, TUI, VS Code i Obsidian już mówią przesłanką. Nie otwieraj SQLite ponownie, żeby „ulepszyć” podgląd.
