# Purpose

Git stores what a human chose to record. A coding agent tests hypotheses in volume, backtracks, rewrites the premise, and forgets the session. The next commit does not say which measurement still competes, nor why the other was abandoned.

ACVC exists for that memory.

The object is the variant: a hypothesis with a premise, a Merkle tree, and append-only trials. The campaign declares the metrics. The frontier is the set of what measurement has not yet beaten. Recall finds the premise by text, with the status and the parent.

The motive is the next session. It needs to find what still competes without rereading the chat, without treating the latest `score` as the truth, and without merging two hypotheses that measure incomparable things.

Git remains the deposit of the winning variant into a checkout that already exists. ACVC does not replace Git history and does not merge.
